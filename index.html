Como este portal funciona

Este é um protótipo de agregador. Ele não copia nem republica o conteúdo das matérias — reúne manchete, um resumo curto e a fonte, e sempre leva você para ler a íntegra no veículo original.

  1. Um coletor lê periodicamente os feeds RSS públicos de cada veículo (BBC News Brasil, CNN Brasil, G1, The Guardian, El País, Reuters, Le Monde Diplomatique Brasil, entre outros).
  2. As notícias são classificadas por editoria — Brasil, Internacional, Economia, Comércio Internacional — cada uma com sua própria página.
  3. Cada card leva direto para a fonte original, com o crédito sempre visível.
Nota: as manchetes são dados de exemplo (mock). Os links "ler no original" apontam para o portal real de cada fonte — numa versão com RSS ao vivo, apontariam para a URL exata de cada matéria.
